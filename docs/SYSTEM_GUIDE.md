# NexusOS Enterprise HRMS - System Guide

Welcome to the comprehensive walkthrough of NexusOS. This guide provides a step-by-step visual overview of the system's core workflows and administrative controls.

---

## 1. Authentication & Onboarding

### Secure Authentication
The entry point to the NexusOS ecosystem. Users can sign in using corporate credentials or Google OAuth for a seamless experience.

![Login Page](./assets/Screenshot%202026-04-26%20040524.png)

### Account Security
Upon first login, users are required to establish a backup password to ensure maximum enterprise security, even when using third-party authentication.

![Password Setup](./assets/Screenshot%202026-04-26%20040546.png)

## 2. Organization Setup

### Identity Configuration
Establish your company's core routing profile and aesthetic identity. This stage defines the foundational CSS variables that will brand your entire workspace.

![Organization Data](./assets/Screenshot%202026-04-26%20040617.png)

### Visual Asset Management
Upload your corporate logo to finalize the branding of your tenant deployment. NexusOS supports high-fidelity SVG, PNG, and JPG formats.
